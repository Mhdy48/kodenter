Kodenter

A modern and responsive educational landing page built with HTML and CSS.

🚀 About The Project

Kodenter is a clean and responsive web design landing page created for showcasing programming and web development courses. The project focuses on modern UI design, responsive layouts, reusable components, and semantic HTML structure.

✨ Features

- Responsive Design
- Modern UI Layout
- Semantic HTML Structure
- CSS Grid & Flexbox
- Hero Section
- Features Section
- Statistics Section
- Popular Courses Section
- Newsletter Subscription Form
- Social Media Links
- Mobile Navigation Menu

🛠 Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Font Awesome
